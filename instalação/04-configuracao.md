# Configuração Inicial do Sistema

## Entrada no sistema instalado

### Comando utilizado
```
arch-chroot /mnt
```
### Resultado 

img 

### Explicação
O arch-chroot permite acessar o sistema recém-instalado como se ele já estivesse iniciado.

### Aprendizado
A partir desse momento, todas as configurações realizadas serão aplicadas diretamente ao sistema instalado no disco.
